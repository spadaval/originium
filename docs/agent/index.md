# Agent Process

Originium uses Beads and an agent-factory role model to coordinate agent work.

Start here when the task is about process, backlog structure, orchestration, or
handoff:

- [Constitution](constitution.md): principles for planning, proof, roles, and
  durable context.
- [Beads](beads.md): tracker commands and issue quality rules.
- [Quality](../architecture/quality/index.md): validation catalog and error
  policy.

The product model lives in [CONTEXT.md](../../CONTEXT.md), and the product
target lives in [SPEC.md](../../SPEC.md).
